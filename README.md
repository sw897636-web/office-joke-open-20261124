## The joke

> I typed 'per my last email' and instantly felt the kind of power that should require a license and a background check.

## How it works

`main.ts` (Node 22, stdlib only) writes the single-line joke to `/output/entry.txt`. Deterministic — the same text on every run, no network access.

```sh
node main.ts
```
